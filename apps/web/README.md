# VOXDECK — web (Next.js)

Primary product surface for the monorepo (`@voxdeck/web`).

```powershell
# from repo root
npm install
npm run dev
# http://localhost:3010
```

Design-first mode works without Supabase credentials (see `.env.local.example`).
Plug in Supabase + LLM keys when you want real auth/DB/Q&A.
